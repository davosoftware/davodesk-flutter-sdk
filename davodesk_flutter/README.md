# davodesk_flutter

DavoDesk in-app support for Flutter apps: the customer's conversations, help articles and
live chat with the support team, as ready-made screens. The client under them is also
available on its own, for an app that draws its own screens.

**Status:** being built. Not published; the example app in this repo uses it by path.

Everything the SDK does goes through the public DavoDesk API. An app may call that API
directly instead (`support-api/docs/HOST_APP_INTEGRATION.md`).
